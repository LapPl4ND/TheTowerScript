# 🗼 The Tower Script

A lightweight Roblox script for **The Tower**, featuring a clean interface with item ESP and teleport functionality to improve navigation and item collection.

---

## ✨ Features

- 👁️ Item ESP
- 📍 Teleport to selected items
- 🎯 Select target flare
- ⚡ Lightweight and responsive UI
- 🎮 Easy keyboard controls

## ⌨️ Controls

| Key | Action |
|------|--------|
| **Insert** | Open / Close Menu |
| **J / K** | Navigate through items |
| **P** | Teleport to selected item |
| **ESP** | Toggle Item ESP |
